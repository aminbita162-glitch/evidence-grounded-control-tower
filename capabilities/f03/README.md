# Free-Time Clock & Cost Shield

F03 evaluates verified movement events against versioned tariff terms and calendars at the recorded evaluation instant. The report includes each container’s free period, suspensions, accrued charges and projected savings. Charges remain grouped by currency. The canonical container set comes from F01.

The case capability evaluation route and the CLI expose the same report. The timeline shows event citations and the latest effective time for operational actions. Synthetic scenarios exercise the free-time boundary, working days, tiered rates, daylight saving and verification rules.
