# Valuation Anomaly

K05 consumes verified F01 shipment facts and explicit, versioned FX, valuation rule, reference and calibration packs. The documentary comparison uses the declared date and compares at the currency's minor-unit precision. The reference comparison uses normalized positive line values and a quantity-weighted total for each code. A group with fewer than 30 observations falls back to its parent when the parent qualifies.

K05 uses SYNTHETIC calibration. On the SYNTHETIC calibration distribution, and assuming exchangeability, a unit value generated by the reference process lies inside the interval with probability at least 90 percent (marginal). This statement does not apply to real prices and is not a valuation ruling.

The view displays positions and directions. Reviewers and administrators can also see the interval bounds. The output records the calibration artifact ID, digest and validation class. The evaluation record commits to the normalized inputs, output, configuration and pack versions.

Invoke K05 through the case evaluation API or the CLI evaluate capability filter. The synthetic scenarios in `data/scenarios/k05` describe the expected decisions and reason codes. Registered sources with unverified rights or validity do not enable real-data rules.
