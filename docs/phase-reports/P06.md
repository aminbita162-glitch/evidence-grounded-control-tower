## Self-review (§9.3)

1. **id**: P06-SR-01
   **category**: DEBT
   **evidence**: kernel/rules/_generated/evaluator.py is excluded from mypy (pyproject.toml line 62); the generated evaluator has untyped functions
   **impact**: The generated evaluator is not type-checked; type errors in generated code could go undetected
   **question**: Should the evaluator generator produce type-annotated output to enable mypy checking?

2. **id**: P06-SR-02
   **category**: RISK
   **evidence**: The xdist INTERNALERROR (KeyError in worker_workerfinished) occurs intermittently when running the full gate suite with `uv run` without sourcing `.venv/bin/activate` first
   **impact**: The pre-push hook may intermittently fail on the unit gate due to a coverage/xdist race condition
   **question**: Should the unit gate command be adjusted to use `-n0` or should the pre-push hook source the venv before running?

3. **id**: P06-SR-03
   **category**: DEBT
   **evidence**: The pack schema (schemas/pack.json) was extended with additive fields (sources, declared_label, owning_capability) but nested rule definitions are not in the JSON Schema; they are validated by the validator (T02) using manual checks
   **impact**: The JSON Schema does not fully describe the pack structure; a full schema validator (jsonschema) is not available
   **question**: Should jsonschema be added as a dependency for full schema validation?

4. **id**: P06-SR-04
   **category**: GAP
   **evidence**: The Pack Authoring Kit's `pack check` does not perturb thresholds and window edges by one unit as described in the directive (it checks for firing/non-firing fixtures only)
   **impact**: The under-tested threshold detection is not fully implemented
   **question**: Should the pack check command be extended to perturb thresholds and window edges?

5. **id**: P06-SR-05
   **category**: DEBT
   **evidence**: The DateAdd and DateDiff expression types are parsed by the DSL parser (T01) but not handled by the generated evaluator (T04); they are only in the reference interpreter
   **impact**: The differential test does not cover DateAdd/DateDiff expressions
   **question**: Should the generated evaluator include DateAdd and DateDiff dispatch?
