# Phase 13 solver measurements

Source SYN-P13-SOLVER-BENCH carries the SYNTHETIC label. The benchmark ran 60 integer models on macOS arm64 using CP-SAT and Z3. Every case used fixed seed 17 and compared one worker with two workers.

| Measurement | Value |
|---|---:|
| Median latency | 1.912 ms |
| 95th-percentile latency | 5.77 ms |
| Metered provider cost per case | EUR 0 |

The cost reflects solver calls to locally installed packages. Infrastructure cost was not measured.
